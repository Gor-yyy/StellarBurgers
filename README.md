# Stellar Burgers — UI Test Automation

## About the Project

This project contains automated UI tests for the Stellar Burgers application.

The goal was to verify user interface functionality related to user registration, authentication, and the burger constructor.

## What Was Tested

### User Registration

- Successful user registration.
- Registration with an invalid password.

### User Login

- Login through different entry points in the application.

### Burger Constructor

- Navigation to the Buns section.
- Navigation to the Sauces section.
- Navigation to the Fillings section.

## Tools and Technologies

- Java
- Maven
- JUnit 4
- Selenium WebDriver
- Allure
